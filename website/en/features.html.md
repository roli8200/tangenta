Features

# Every tool.  One program.

From the first line to the printed sheet: everything TANGENTA can do, at a glance.

### Draw

- Rectangle, ellipse, pie and arc
- Polygon, star and complex star
- Spiral and graph paper
- Freehand, 2-point line, Bézier, pen and B-spline
- 3-point rectangle, ellipse and curve
- Artistic media: brushes, sprayer, calligraphy
- Perfect shapes: basic, arrow, flowchart, banner and star shapes
- Tables with merged cells
- Dimensions and angular dimensions
- Connectors that follow their objects
- QR codes you can edit at any time

### Shape

- Shape tool with every node type
- Knife, eraser and crop
- Weld, intersect, trim
- Front minus back, back minus front
- Combine and break apart
- Convert outline to object
- Join curves
- Shaping docker with preview
- Smart Fill, even between open lines
- Shape tool directly on rectangles, polygons and stars
- Round corners in the Corners docker

### Fill and outline

- Uniform fill with colour picker
- Linear, radial and conical gradients
- Pattern and texture fills
- Mesh fill
- Interactive fill right on the object
- Outline pen with line styles and arrowheads
- Eyedropper and copy attributes
- Blend modes such as Multiply

### Effects

- Blend along a path, with gradients too
- Contour inside and outside
- Extrude
- Envelope with presets
- Perspective
- Drop shadow, inner shadow and block shadow
- Transparency with blend modes
- Lens with fish eye and other types
- Bevel and blur
- 3D rotation of extrusions
- SuperClip: place content inside a frame

### Text

- Artistic and paragraph text
- Linked text frames with overflow
- Text on path
- Bullets and drop caps
- Tabs and paragraph formatting
- Hyphenation
- Spell checking and QuickCorrect
- Font substitution on PDF import

### Images

- Import up to camera RAW (NEF, CR2, CR3, ARW, DNG …)
- Tone curve, brightness, contrast, colour balance
- Hue, saturation and filters
- Crop and mask
- SuperTrace: turn bitmaps into vectors
- Image search across eight libraries

### Bitmap effects

- More than 60 effects in 13 groups
- Live on any object, as an editable stack
- Blur, sharpen, artistic, 3D, distort
- Frame effect, page curl, cylinder
- Colour corrections with eyedropper and ranges
- Photo mosaic and pointillizer

### Document

- Multiple pages with a master page and Pages docker
- Multi-page view, resize pages by dragging
- Layers and Object Manager
- Symbols and clones
- Guidelines, dynamic guides, grid
- Snapping to nodes, centres, edges and the page
- Unlimited undo
- Its own open file format (.vek)

### Print

- Print preview
- Imposition: booklet, signature, n-up, step-and-repeat
- Crop and fold marks, bleed
- Labels
- PDF with presets and preflight

### Automate

- JavaScript scripts with an editor
- Its own scripting API (tg)
- AI assistant with 18 tools
- Image search and web search for the AI

### Interface

- In seven languages
- Your own shortcut for every command
- Dockers as tabs or stacked
- Number fields that calculate (297/2)
- Font search by part of the name

**01** / In detail

## What makes TANGENTA special.

Nine features worth knowing, each with a video that shows it on a real example.

### Smart Fill

Click inside an area enclosed by lines and shapes and TANGENTA turns it into an object of its own, even between open lines that merely cross. Logos and patterns grow from a few guide lines.

[Watch the video (3:05) →](https://www.youtube.com/watch?v=jchlvRJj8hI)

### Blend along a path

Any number of steps between two objects, in shape, colour and gradient. The steps can follow a path such as a spiral, in reverse order if you like.

[Watch the video (3:42) →](https://www.youtube.com/watch?v=AO6bjf3GnCc)

### Live bitmap effects

More than 60 effects in 13 groups, from soften to oil paint and page curl. They sit on the object as a stack and stay editable, switchable and removable at any time.

[Watch the video (6:35) →](https://www.youtube.com/watch?v=zhL5F3JGeNI)

### SuperClip

Place photos, patterns and graphics inside a frame: a shape, a circle or even text. The content can still be moved and replaced.

[Watch the video (4:23) →](https://www.youtube.com/watch?v=2BEWZDCxU9A)

### Envelope

Bend text and graphics into a shape, from presets or following the outline of any object, and adjust it again at any time.

[Watch the video (3:27) →](https://www.youtube.com/watch?v=mULVFW4GiXg)

### Cut lines for laser and plotter

The outline of an image becomes a clean contour with an offset, ready for laser cutters and vinyl plotters.

[Watch the video (4:53) →](https://www.youtube.com/watch?v=NNYndGIMJc4)

### Multiple pages

Add, switch and manage pages in the Pages docker, see all pages side by side and resize a page by dragging it with the mouse.

[Watch the video (4:10) →](https://www.youtube.com/watch?v=snarzYb2rqY)

### Image search

Find free photos and icons in eight libraries and insert them with author and licence, right inside the program.

[Watch the video (4:37) →](https://www.youtube.com/watch?v=gYRQ35fvKL0)

### AI assistant

A logo, text or photo on request: the assistant draws in your document and checks its own result.

[Watch the video (4:53) →](https://www.youtube.com/watch?v=38FLp_RBsBg)

[All tutorials →](https://tangenta.ch/en/tutorials.html)

**02** / Workspace

## Dockers where you need them.

Object Manager, Object Properties, Shaping, Transformations, Symbols, Lens, Envelope, Scripts and AI dock on the right, as tabs or stacked. The property bar at the top always shows the fields for the selected object.

- Object Manager with pages, layers and master page
- Property bar for every tool and object type
- Status bar with the fill and outline of the selection
- Colour palette on the right edge

![TANGENTA with Object Manager and Object Properties, the poster title selected](https://tangenta.ch/img/06-andockfenster.png)

**03** / Settings

## Every setting where you expect it.

The Options dialog (Ctrl+J) arranges Workspace, Document and Global in a tree, the way you are used to: snapping, guidelines, tools, saving, text, spelling, image search, AI and much more.

![Options dialog showing the snapping page](https://tangenta.ch/img/08-optionen.png)

**04** / File formats

## In and out.

### Import

CDR · CMX · AI · SVG · PDF · EPS · PS · DXF · PNG · JPEG · TIFF · WebP · BMP · GIF · NEF · CR2 · CR3 · ARW · DNG

### Export

PDF · SVG · EPS · DXF · PNG · JPEG · TIFF · WebP · PSD · HTML

CDR, CMX, AI, PDF, SVG and EPS are imported as editable curves and text. For EPS and PS, TANGENTA uses Ghostscript.
