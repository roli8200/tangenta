01 / Windows

Installing on Windows

  1. Download TANGENTA-0.85-x64-setup.exe and run it.
  2. Accept the licence and choose Install. The setup needs administrator rights and installs for all users.
  3. Open TANGENTA from the Start menu. From then on, .vek files open with a double-click.

If Windows shows “Windows protected your PC”, click More info and then Run anyway. The packages are not yet digitally signed.

02 / Linux

Installing on Linux

  1. Download the package for your system:
  2. Install it in a terminal: sudo apt install ./tangenta_0.85-1~debian12_amd64.deb (adjust the file name).
  3. Open TANGENTA from the application menu or type tangenta. Remove it with sudo apt remove tangenta.

04 / For IT

Silent installation.

For GPO, Intune, SCCM or your own scripts. Both packages install to C:\Program Files\TANGENTA; a newer version replaces an older one.

Setup, silentTANGENTA-0.85-x64-setup.exe /quiet
Setup with progressTANGENTA-0.85-x64-setup.exe /passive
Folder and desktop shortcutTANGENTA-0.85-x64-setup.exe /quiet InstallFolder="D:\Programs\TANGENTA" DesktopShortcut=1
MSI, silentmsiexec /i TANGENTA-0.85-x64.msi /qn
MSI with logmsiexec /i TANGENTA-0.85-x64.msi /qn /l*v C:\Temp\tangenta.log
Uninstallmsiexec /x TANGENTA-0.85-x64.msi /qn
