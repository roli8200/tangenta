# Bedienung

| Aktion | Wirkung |
|---|---|
| Klick | auswählen; Umschalt+Klick ergänzt/entfernt |
| Ziehen im Leeren | Auswahlrahmen, nur vollständig umschlossene Objekte |
| Eckgriff ziehen | proportional skalieren; Umschalt vom Mittelpunkt, Strg in 100-%-Schritten |
| Seitengriff ziehen | breiter/schmaler bzw. höher/flacher |
| zweiter Klick auf die Auswahl | Dreh-/Neigemodus; Ecken drehen (Strg 15°), Seiten neigen, ⊙ verschiebbar |
| Objekt ziehen | verschieben; Strg nur waagrecht/senkrecht |
| Pfeiltasten | schubsen um den Verschiebungsabstand der Seite (Vorgabe 0,1 mm); Umschalt zehnfach, Strg ein Zehntel |
| F6 / F7 / Y / F5 / I / F10 / X / Z / Leertaste | Rechteck / Ellipse / Polygon / Freihand / künstlerische Medien / Form / Radierer / Zoom / zwischen Auswahl und letztem Zeichenwerkzeug wechseln |
| Werkzeuge mit Dreieck | Ausklappliste: Klick aufs Dreieck oder lang drücken; der Knopf zeigt das zuletzt gewählte Werkzeug |
| Rechteck, Ellipse, Polygon: Ziehen | Strg = Quadrat/Kreis, Umschalt = vom Mittelpunkt; Ellipse auch als Kreissegment oder Bogen, Sterne mit Spitzen und Schärfe |
| Künstlerische Medien: Ziehen | geglätteter Strich mit Breitenverlauf (Voreinstellung) oder fester Feder (Kalligrafisch) |
| Beschneiden | Rahmen ziehen und anpassen, Doppelklick oder Eingabe schneidet die Auswahl (sonst die Seite) zu |
| Messer / Radierer | Linie durch Objekte teilt sie; Radierer (X) entfernt entlang der Spur, Stärke und Spitze in der Leiste |
| Rechtsklick auf Objekte | Kontextmenü: In Kurven konvertieren, Kombination aufheben, Rückgängig, Ausschneiden, Kopieren, Löschen, Sperren, Anordnung |
| Strg+Bild auf / ab | eins nach vorn / hinten; Umschalt+Bild auf/ab auf der Ebene, Strg+Pos1/Ende auf der Seite |
| Strg+L / Strg+K | Kombinieren / Kombination aufheben |
| Freihand: Klick, Klick | gerade Linie; Ziehen zeichnet frei; Klick auf ein Ende der gewählten Kurve setzt sie fort, Ende auf dem Anfang schliesst sie |
| 2-Punkt-Linie: Ziehen | gerade Linie; Strg rastet in 15°-Schritten ein (auch beim Freihandwerkzeug) |
| Bézier: Klick / Ziehen | Klick setzt einen Eckknoten, Ziehen einen symmetrischen Kurvenknoten; Klick auf den ersten Knoten schliesst, Doppelklick oder Eingabe beendet, Esc verwirft |
| Strg+Q | In Kurven konvertieren (Grundformen werden zu Kurven, künstlerische Medien werden aufgebrochen) |
| Form: Knoten anklicken/ziehen | wählen und verschieben; Umschalt ergänzt, Rahmen wählt mehrere, Strg nur waagrecht/senkrecht |
| Form: Rechtsklick auf Knoten | Hinzufügen, Löschen, In Linie, In Kurve, Spitz/Glatt/Symmetrisch, Schliessen, Richtung umkehren (auch in der Eigenschaftsleiste) |
| Form: Kurvensegment ziehen | verbiegt es; Steuerpunkte an gewählten Knoten ziehen |
| Form: Doppelklick | auf der Linie: Knoten einfügen; auf einem Knoten: löschen; Entf löscht gewählte Knoten |
| Unschärfe (Eigenschaftsleiste) | Gaussscher Weichzeichner in mm, für jedes Objekt und jede Gruppe |
| Lineal ziehen | Hilfslinie; anklicken und ziehen verschiebt, ins Lineal zurück oder Entf löscht |
| Ausrichten an | Einrasten an Knoten, Mittelpunkt, Rand, Hilfslinien, Seite (Ansicht-Menü/Standardleiste) |
| Eigenschaftsleiste | Lage, Grösse, Skalierung, Winkel, Spiegeln, Pfeilspitzen, Linienstil, Konturbreite; je Objekttyp eigene Felder |
| Palette links/rechts | Füllung / Kontur; Knopf oben klappt die Farbleiste auf |
| Umschalt+F11 / F11 | Gleichmässige Füllung (Farbdialog mit Pipette) / Farbverlauf |
| G | Interaktive Füllung: Verlauf aufs Objekt ziehen, Endpunkt wählen und Palettenfarbe anklicken |
| Hilfslinie zweimal anklicken | Drehgriffe an den Enden; Drehpunkt ⊙ frei verschiebbar, auch neben die Linie; Winkel/Anker in der Eigenschaftsleiste |
| Zahlenfelder | rechnen: `297/2`, `(210-20)*0,5`; Enter oder Feld verlassen übernimmt |
| Mausrad | zoomen; Strg/Umschalt rollen, mittlere Taste schwenken |

Weitere Kürzel stehen in den Menüs und unter Extras > Optionen > Anpassung > Befehle.
